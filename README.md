# Atacadão Valinhos

Projeto de presença digital para o **Atacadão Limpeza e Descartáveis — Valinhos/SP**.

Desenvolvido pela **Olegario Tech**.

## Estrutura de trabalho
- `main`: base estável
- `v1-concept`: conceito visual e comercial da primeira versão

## Direção inicial
- preservar o logotipo oficial e a identidade azul + laranja;
- experiência mobile-first;
- catálogo orientado por necessidade;
- duas unidades em Valinhos;
- conversão por WhatsApp;
- área dedicada a empresas / B2B.
